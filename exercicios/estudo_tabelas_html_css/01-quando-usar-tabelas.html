Aula 01 — Quando usar tabelas

Tabelas são adequadas para apresentar dados tabulares, como notas, horários e comparações. Não use tabelas para montar o layout inteiro de um site; para isso, use CSS Flexbox ou Grid.

Regra prática: se os dados fazem sentido organizados em linhas e colunas, uma tabela pode ser a escolha certa.
